# VELORA / VELORAMINER

نسخه چندزبانه پروژه با رابط کاربری انگلیسی، فارسی، روسی و عربی.

## وضعیت فعلی

این بسته برای بررسی و استقرار آزمایشی روی VPS آماده‌سازی شده است؛ هنوز تأیید نهایی production یا Mainnet نیست. اتصال TON Connect و تأیید مالکیت کیف پول با TON Proof در کد اضافه شده، اما فعال‌سازی آن به دامنه HTTPS، تنظیم Testnet و اجرای تست end-to-end نیاز دارد. موجودی ماینینگ، استیک و برداشت در رابط فعلی همچنان نمایشی و سمت مرورگر است. تا پایان آزمون end-to-end روی TON Testnet، تراکنش واقعی و پرداخت خودکار را فعال نکنید.

## استقرار روی VPS

راهنمای فارسی را در [`SETUP-FA.md`](./SETUP-FA.md) ببینید. برای استقرار با Docker Compose به دامنه‌ای نیاز است که به IPv4 سرور اشاره کند. فایل `.env.example` را به `.env` تبدیل کنید و فقط روی سرور مقادیر محرمانه را وارد کنید.

```bash
docker compose up -d --build
```

## توسعه و بررسی

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run start
```

از قراردادن `.env`، توکن ربات، عبارت بازیابی یا کلید خصوصی در GitHub خودداری کنید.
