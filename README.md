# VELORA / VELORAMINER

نسخه چندزبانه پروژه با رابط کاربری انگلیسی، فارسی، روسی و عربی.

## وضعیت فعلی

این بسته برای بررسی و استقرار آزمایشی روی VPS آماده‌سازی شده است؛ هنوز تأیید نهایی production یا Mainnet نیست. ماینینگ، استیک و تسک‌ها در نسخه فعلی سمت مرورگر اجرا می‌شوند و اتصال کامل رابط کاربری به خرید، اتصال کیف پول و برداشت‌های سمت سرور تکمیل نشده است. تا پایان آزمون end-to-end روی TON Testnet، تراکنش واقعی و پرداخت خودکار را فعال نکنید.

## استقرار روی VPS

راهنمای فارسی را در [`SETUP-FA.md`](./SETUP-FA.md) ببینید. برای استقرار با Docker Compose به دامنه‌ای نیاز است که به IPv4 سرور اشاره کند. فایل `.env.example` را به `.env` تبدیل کنید و فقط روی سرور مقادیر محرمانه را وارد کنید.

```bash
docker compose up -d --build
```

## توسعه و بررسی

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run start
```

از قراردادن `.env`، توکن ربات، عبارت بازیابی یا کلید خصوصی در GitHub خودداری کنید.
